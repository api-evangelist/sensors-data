# Sensors Data (神策数据)

> Sensors Data is a customer data analytics and CDP (Customer Data Platform) company. Its platform unifies customer data across channels into real-time profiles and provides product analytics, user profiling, marketing/ad attribution, A/B testing, and smart-operations tooling. Sensors Data processes 250+ billion data points daily, ships 50+ data-collection SDKs, and serves 2,000+ enterprise customers, with both cloud and on-premise deployment. An OpenAPI is exposed for ecosystem integration; per-language SDKs handle client- and server-side event tracking.

## Products
- [Real-time CDP (Sensors Data Universe / 神策数界)](https://www.sensorsdata.com/): Unifies multi-channel data into real-time customer profiles with ID-mapping, segmentation, and an OpenAPI for integration.
- [Product Analytics (神策分析)](https://www.sensorsdata.com/): Behavioral analytics for product teams.
- [User Profiles (神策用户画像)](https://www.sensorsdata.com/): User segmentation and tagging.
- [Ads Tracking (神策广告分析)](https://www.sensorsdata.com/): Cross-channel marketing/ad attribution and ROI.
- [Smart Operations (神策智能运营)](https://www.sensorsdata.com/): Marketing automation.
- [A/B Testing (神策A/B测试)](https://www.sensorsdata.com/): Experimentation platform.
